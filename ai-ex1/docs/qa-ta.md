- Q: For the successor function, is it obligatory to preserve all successors that might be a part of an optimal plan? For example, can we prune the "re-ordering" successors? That is, if there is an optimal plan x-y-z and an equivalent optimal plan y-x-z, can we prune the successor(s) that lead to y-x-z while preserving x-y-z? An example would be a pruning rule "exclude actions that can wait for a later time"
- A: Yes, you may prune, as long as your search still returns anoptimal plan. The condition is: from every state you keep, at leastone optimal plan must still be reachable, so succ(s) has to containthe next action of some optimal plan from s. Pruning permutations isfine in principle. If x and y are independent (neither one disablesthe other or changes what the other needs), and (s[x])[y]=(s[y])[x],then x-y-z and y-x-z cost the same and reach the same state, sokeeping one is enough. Be careful, though: a rule like “excludeactions that can wait” can prune x in favor of y and y in favor of xat the same time, which loses both. A safe version fixes onecanonical order, e.g. don’t apply x right after y if they areindependent and x has a lower index. This idea is studied under thename stubborn sets (partial order reduction). If you’re curious, seeWehrle and Helmert, “Efficient Stubborn Sets: Generalized Algorithmsand Selection Strategies” (ICAPS 2014). For domains with capacitieslike ours, see also Wilhelm, Steinmetz and Hoffmann, “On StubbornSets and Planning with Resources” (ICAPS 2018), which shows thatactions using the same resource can often still be reordered.
